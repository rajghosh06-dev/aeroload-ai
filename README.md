# ✈️ AeroLoad-AI

**Aircraft Cargo Weight-and-Balance & Hazmat Placement Engine**

AeroLoad-AI is an AI-based aircraft cargo planning prototype that
formulates cargo placement as a Constraint Satisfaction Problem (CSP).

## Core AI Concepts

- Constraint Satisfaction Problems (CSP)
- Constraint Propagation
- AC-3
- Backtracking Search
- Minimum Remaining Values (MRV)
- Least Constraining Value (LCV)
- Local Search
- Min-Conflicts
- Knowledge Representation
- Rule-Based Reasoning

## Technology Stack

- Python 3.12
- Miniconda
- Streamlit
- Pandas
- Plotly
- pytest
